# Roadmap — Physics-Informed ML for Financial Market Dynamics

Last updated: 11 October 2026

## Decisions (fixed; change only with a recorded reason)

| # | Decision | Reason |
|---|---|---|
| D1 | Data: Yahoo Finance CSV via `python/download_sp500.py`, not Mathematica `FinancialData` | `FinancialData` historical downloads fail; the CSV is validated (see `data_log.md`) |
| D2 | Price variable: Close (identical to Adj Close for the index) | Verified: 0 differences |
| D3 | Time measured in trading sessions; no annualization | Matches the target definition |
| D4 | Target: RV_{t,t+5} = sqrt( sum_{i=1}^{5} r_{t+i}^2 ) | Project definition; verified leakage-free |
| D5 | Physics features come **after** the baseline pipeline | A baseline must exist before improvement can be measured |
| D6 | Add HAR features: \|r_t\| (daily), RV5_past (weekly), RV22_past (monthly) | Standard realized-volatility benchmark (Corsi, 2009); matches the slow decay of the \|r\| ACF |
| D7 | Momentum M10_t = ln(P_t / P_{t-10}) = sum_{i=0}^{9} r_{t-i} | Additive, consistent with log returns, uses past data only |
| D8 | Rolling SD sigma20_t: demeaned sample SD over r_{t-19..t}, divisor 19 | As in the project plan. Note: per-day units, not the same quantity as RV5. |
| D9 | Feature list `features_v1` is fixed before any model is trained | Prevents tuning features to the test period |
| D10 | Split 65/15/20 chronological; purge the last 5 rows before each boundary | No shuffling; no target overlap across splits |
| D11 | Scalers and hyperparameters fit on training/validation only; test evaluated once | Avoids leakage and test-set overfitting |
| D12 | Metrics: MAE, RMSE, out-of-sample R², QLIKE; Diebold–Mariano test vs naive with HAC errors | QLIKE is robust to noisy volatility proxies (Patton, 2011); HAC is needed because overlapping targets make errors autocorrelated |
| D13 | Notebooks: `01_Data_Collection_and_EDA.nb` (covers the plan's collection + EDA), `02_Feature_Engineering.nb` | 01 already exists and is committed |
| D14 | Raw and processed data are not committed; regenerated by scripts/notebooks | Yahoo terms; reproducibility |
| D15 | Close is kept as a reference column, not a model input | Non-stationary price level would let models learn the time period |
